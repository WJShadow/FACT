FACT notebook datasets download
===============================

Rep data (manual download only)
--------------------------------
https://drive.google.com/drive/folders/1N88iCF093rot6Pn70JHtC7WBhAkL3ddz?usp=sharing

Download the NeuroFinder-Registered and STA_Evaluation folders from this link.
Place both folders directly beneath data\; do not create an additional nested
folder such as data\STA_Evaluation\STA_Evaluation\.

Demo data
---------
Manual ZIP download folder:
https://drive.google.com/drive/folders/1c3iSZWt9nLQAtM5WBqrPggZ9tPRCRXKl?usp=sharing

Download data.zip individually, not the whole Drive folder or Download all.
Extract its contained data folder into the repository root, so the demo files
are under data\Demo\. Do not create an extra data\data\ folder.
For manual GUI installation, download GUI.zip separately from the same link
and place its contained GUI folder beside data. Avoid GUI\GUI\ nesting.

In a cloned repository, double-click data\Download Demo data_(RUN ME).bat to
download the five required TIFFs automatically. Missing-file repair downloads
only missing TIFFs. The GUI downloader also offers basic or all-demo options.

For a standalone GUI trial with only MouseBrainCortex initially included:
https://drive.google.com/file/d/1moZK8P6hIuX0UCIKTAgESQTkQ63N6kIB/view?usp=drive_link
Extract the full light ZIP and run GUI\FACT-Pipeline.exe. Its optional
data\Download Additional Demo Data_(RUN ME).bat downloads CA1+CA3 together,
Meso, Rhesus, combinations, or all remaining demos. Restart the GUI afterward
and select the downloaded data through the Demo menu.

Required layout
---------------
data\
|-- Demo\
|   |-- GUI-Config\
|   |   `-- five .fact.json configurations
|   |-- Meso\Data_meso_strip.tif
|   |-- Mouse hippocampus\Data_CA1.tif
|   |-- Mouse hippocampus\Data_CA3.tif
|   |-- MouseBrainCortex\MouseBrainCortex_quat.tiff
|   `-- Rhesus\Rhesus_quat.tif
|-- NeuroFinder-Registered\
|   |-- 0100_test\ and 0100_train\
|   |-- 0101_test\ and 0101_train\
|   |-- 0200_test\ and 0200_train\
|   `-- 0201_test\ and 0201_train\
`-- STA_Evaluation\
    |-- Vid01.tiff through Vid08.tiff
    `-- GT\Vid01.mat through Vid08.mat

The Rep_NF notebooks require TIFF and __GTmasks.mat pairs beneath
data\NeuroFinder-Registered. The Rep_EVA_STAccuracy notebooks require the
Vid01-Vid08 TIFF files and matching GT MAT files beneath data\STA_Evaluation.
Run Jupyter with the repository root as its working directory after the data
have been installed.
